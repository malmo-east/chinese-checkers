# Китайские шашки

Минималистичная мобильная игра «Китайские шашки» (Chinese Checkers / Halma)
для iOS и Android, написанная на Flutter.

* Цель — провести все 10 фишек в противоположный угол звезды.
* В этой реализации нет рекламы, серверов и аналитики — всё работает офлайн.
* Боты «человечные»: каждый думает только о своих фишках и не объединяется
  против живого игрока — стиль казуальных настольных игр начала 2000‑х.

## Скриншоты / фичи

* Главное меню → выбор количества ботов (1 / 2 / 3 / 5), сложности
  (Лёгкий / Средний / Сложный) и цвета фишек.
* Игровое поле звездой на 121 клетку, поддерживает 2, 3, 4 и 6 игроков.
* Подсветка выбранной фишки и всех доступных ходов (включая цепочки прыжков).
* Анимация прыжков с лёгким «подскоком».
* Тёмная минималистичная палитра без декораций.

## Структура проекта

```
lib/
  main.dart                 — точка входа, тема Material 3 (dark)
  theme/colors.dart         — палитра
  models/
    hex_coord.dart          — кубические координаты шестиугольной сетки
    board.dart              — статика поля (121 клетка, 6 треугольников)
    move.dart               — одиночный шаг или цепочка прыжков
    player.dart             — игрок (id, цвет, тип, треугольник старта/цели)
    game_state.dart         — позиции фишек, генерация ходов, проверка победы
  ai/
    bot.dart                — «человечный» 1‑plyhe эвристический бот
  widgets/
    board_view.dart         — отрисовка поля, хит‑тест, анимация
  screens/
    home_screen.dart        — стартовый экран
    setup_screen.dart       — настройка партии
    game_screen.dart        — собственно партия
test/
  game_test.dart            — юнит‑тесты геометрии, ходов и бота
```

## Как собрать

1. Установите Flutter 3.24+: https://docs.flutter.dev/get-started/install
2. Подтяните зависимости:

   ```bash
   flutter pub get
   ```

3. Запустите на симуляторе/устройстве:

   ```bash
   flutter run
   ```

4. Сборка релизных артефактов:

   ```bash
   flutter build apk --release          # Android
   flutter build appbundle --release    # Android (Play Store)
   flutter build ios --release          # iOS (нужен macOS + Xcode)
   ```

Если папки `android/` или `ios/` повредились, восстановите их одной командой:

```bash
flutter create --platforms=ios,android --project-name chinese_checkers .
```

## Запуск тестов

flutter test
